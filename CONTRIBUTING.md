# Contributing to ARIA RPG Engine

Thank you for your interest in contributing to the ARIA RPG Engine! This document provides guidelines and instructions for contributing.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or bug fix
4. Make your changes
5. Submit a pull request

## Development Setup

```bash
git clone https://github.com/yourusername/aria-rpg-engine.git
cd aria-rpg-engine
pip install -r requirements.txt
```

## Code Style

- Follow PEP 8 guidelines
- Use meaningful variable and function names
- Add docstrings to all functions and classes
- Write comments for complex logic

## Testing

Before submitting a pull request, ensure all tests pass:

```bash
python -m pytest
```

## Commit Messages

Use clear, descriptive commit messages:
- Use the imperative mood ("Add feature" not "Added feature")
- Keep the first line to 50 characters or less
- Reference issues and pull requests liberally after the first line

## Pull Request Process

1. Update documentation with any new features
2. Add tests for any new functionality
3. Ensure the test suite passes
4. Include a clear description of your changes
5. Link related issues

## Questions?

Feel free to open an issue with the `question` label or reach out to the maintainers.
